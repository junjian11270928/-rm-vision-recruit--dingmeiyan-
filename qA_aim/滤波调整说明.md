# 本次滤波调整

保留识别阈值、关键点、PnP结果与视频。仅修改运动滤波，重新生成预测CSV和曲线。

## 改了什么

1. 保留6维匀速卡尔曼状态：[x,y,z,vx,vy,vz]。
2. 采用连续白噪声加速度模型，按帧间隔dt=1/150积分得到Q。原先独立逐帧加速度扰动的配置，对这段视频的转向适应过慢。
3. x方向允许较大的运动变化；y、z方向采用更小的过程噪声。R区分三个方向，深度观测噪声设得更大。
4. 异常判断改为按方向增大测量方差、减弱更新，不再因一项偏差而连续拒绝整帧。原始观测和误差比较样本不删除。
5. 连续缺测超过0.2秒暂停输出预测，超过0.5秒重新获取有效观测时初始化。

参数在filter_config.json中。process_noise_density是连续加速度噪声谱密度，单位m²/s³，不是每帧加速度标准差；measurement_std_m是测量标准差，单位m。程序内部将其平方构造R。

## 同一批1257个时刻的公平比较

| 指标 | 调整前 | 调整后 |
|---|---:|---:|
| 三维误差RMSE | 0.623m | 0.280m |
| 平均三维距离误差 | 0.464m | 0.222m |
| 最大三维距离误差 | 2.009m | 1.002m |

RMSE降低55.0%。旧版有1257个可比较预测，新版有1482个；全部新版有效比较的RMSE为0.265m。两种统计样本数量不同，不能把0.623和0.265直接作为严格同样本比较。

## 参数如何选

固定测量标准差[0.01,0.015,0.06]m，比较24组Q：x谱密度为0.3、1、3、10、30、100，y/z谱密度为0.001、0.01、0.1、1。
用前半段且其未来比较点仍在前半段的样本排序，选择[30,0.001,0.001]。后半段作连续视频内的时间段检查。
候选表filter_tuning_candidates.csv列出各组结果。选定配置对第一段可比较时刻的RMSE由0.638m降到0.283m，对第二段由0.551m降到0.274m。
这里的比较都是当前录像内的检查，未验证新视频，且PnP未来观测不是独立真值。
另试了加速度状态模型，前半段误差更大，因此本次没有采用。

## 自己再运行

在qA_aim文件夹打开PowerShell，用已有Python环境运行：

```powershell
python qA_aim/run_analysis.py --predict-only
```

该命令复用filter_diagnostics.csv里的原始PnP观测。若重新调了红色识别阈值，必须用 --video 远距离平移 重新分析视频，不能仅复用旧观测。

## 已做的检查与局限

- 理想匀速输入：稳定后0.25秒预测误差小于2mm。
- 截断输入到某一帧，其输出与完整输入在此前完全一致，验证未读取未来数据。
- 缺测超过0.2秒时留空，恢复观测后继续工作。
- 人工加入5m深度异常值，软门限生效，之后恢复。
- 新旧曲线已查看，仍有转向时的匀速外推过冲和PnP深度噪声。本次改动没有修复俯视轨迹弯曲，也不代表最终验收完成。
